# 🎓 UOR Admission Assistant

An AI-powered chatbot that helps students get instant answers about 
University of Rasul (UOR) admissions — programs, eligibility, fees, and deadlines.

## 🚀 Built With
- Python
- Streamlit
- Groq API (LLaMA 3.3 70B)

## ✨ Features
- Real UOR admission data (Fall 2025)
- Program eligibility for all faculties
- Complete fee structure
- Admission calendar & deadlines
- Clean, responsive UI

## ▶️ How to Run Locally
1. Clone the repo
2. Install requirements:
   pip install streamlit groq python-dotenv
3. Create a .env file and add:
   GROQ_API_KEY=your_key_here
4. Run the app:
   streamlit run app.py
